# KII

Локальный прототип персонального ассистента. Сейчас в проекте есть консольное ядро, безопасные базовые действия с Windows и локальный модуль синтеза речи.

## Голос KII

Основной движок — Piper TTS с русским женским голосом `ru_RU-irina-medium`. Он синтезирует речь локально, без отправки текста в облако. Если Piper или модель не установлены, KII пытается использовать системный голос через `pyttsx3`.

Голос настроен на размеренную подачу: скорость системного движка по умолчанию 165 слов в минуту, для Piper используется `length_scale=1.08`. Это даёт спокойную, слегка синтетическую манеру, но не является точной имитацией какого-либо персонажа. Настоящий тембр определяется выбранной моделью.

### Установка на Windows

Открой PowerShell в корневой папке репозитория:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
py -m pip install -r requirements.txt
py -m piper.download_voices ru_RU-irina-medium --data-dir models/voice
```

Если загрузчик положил модель в другое место, укажи её полный путь через переменную окружения:

```powershell
$env:KII_PIPER_MODEL = "C:\полный\путь\ru_RU-irina-medium.onnx"
py main.py
```

Обычно KII ищет модель в `models/voice/ru_RU-irina-medium.onnx`, в корне проекта или в стандартной вложенной папке Piper. Файл модели и соответствующий `.onnx.json` должны лежать рядом. Модель не включена в Git: её размер составляет десятки мегабайт.

### Проверка голоса

После установки запусти:

```powershell
py -c "from voice.tts import TTSEngine; t=TTSEngine(); print('Движок:', t.engine_name); print('Доступен:', t.available); t.speak('Привет. Я KII. Голосовой модуль работает локально.')"
```

### Linux / Ubuntu

В активном виртуальном окружении установи зависимости и модель теми же командами через `python -m pip` и `python -m piper.download_voices`. Для воспроизведения WAV на Linux требуется системный проигрыватель `paplay` или `aplay`. На сервере без аудиоустройства синтез может работать, но физически воспроизводить звук будет нечем.

### Настройки

- `KII_PIPER_MODEL` — полный путь к файлу модели Piper.
- `TTSEngine(rate=165, volume=0.9)` — скорость и громкость резервного системного голоса.
- `TTSEngine(length_scale=1.08)` — темп Piper: значение больше 1 замедляет речь, меньше 1 ускоряет.

### Лицензии

У движка Piper и у конкретной голосовой модели отдельные лицензии. Перед распространением KII или включением TTS в коммерческий установщик проверь лицензии runtime и файла модели.

## Установка KII

Требуется Python 3.10 или новее. Открой PowerShell в папке проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
py -m pip install -r requirements.txt
py main.py
```

Если PowerShell запрещает активацию виртуального окружения, используй интерпретатор напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## Команды прототипа

- `открой блокнот`
- `открой калькулятор`
- `открой проводник`
- `открой paint`
- `открой файл C:\путь\к\файлу.txt`
- `открой папку C:\путь\к\папке`
- `покажи системную информацию`
- `выход`

KII запускает только приложения из разрешённого списка. Для открытия файла или папки он проверяет, что путь существует, и передаёт его системному обработчику. Произвольные команды оболочки не выполняются.

## Текущие ограничения

- Это пока консольный прототип, не полноценный диалоговый ИИ.
- Голосовое распознавание, память, серверная синхронизация и GUI будут отдельными этапами разработки.
