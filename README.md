# KII

Локальный прототип персонального ассистента. Текущий этап: голосовой вывод
через системный TTS и безопасные базовые действия с приложениями, файлами
и системной информацией.

## Требования

- Python 3.10 или новее
- Windows 10/11 для основных команд Windows
- Системный голос Windows; для русского произношения должен быть установлен русский голос

## Установка

Открой PowerShell в папке проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
py -m pip install -r requirements.txt
py main.py
```

Если PowerShell запрещает активацию виртуального окружения, можно запускать
интерпретатор напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## Команды прототипа

- `открой блокнот`
- `открой калькулятор`
- `открой проводник`
- `открой paint`
- `открой файл C:\путь\к\файлу.txt`
- `открой папку C:\путь\к\папке`
- `покажи системную информацию`
- `выход`

KII запускает только приложения из разрешённого списка. Для открытия файла или
папки он проверяет, что путь существует, и передаёт его системному обработчику.
Произвольные команды оболочки не выполняются.

## Текущие ограничения

- Это пока консольный прототип, не полноценный диалоговый ИИ.
- TTS использует установленный системный голос. При отсутствии pyttsx3 или
  проблемах с аудиодвижком остаётся текстовый режим.
- Голосовое распознавание, память, серверная синхронизация и GUI будут отдельными
  этапами разработки.
