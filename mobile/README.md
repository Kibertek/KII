# KII Mobile

Мобильный клиент KII в формате PWA: адаптируется под экран телефона, устанавливается на главный экран и кэширует оболочку для повторного открытия без сети.

## Запуск для разработки

PWA и Service Worker требуют HTTP(S), поэтому не открывай `index.html` напрямую через `file://`.

Из корня репозитория:

```powershell
py -m http.server 8080
```

На компьютере открой `http://localhost:8080/mobile/`. Для открытия на телефоне в той же Wi-Fi сети используй локальный IP компьютера вместо `localhost`. Браузер может ограничивать установку PWA и Service Worker на HTTP по локальному IP. Для постоянной установки понадобится HTTPS-хостинг или сервер KII с HTTPS.

## Установка на Android

1. Разместить папку `mobile` на HTTPS-сайте.
2. Открыть сайт в Chrome на телефоне.
3. В меню браузера выбрать «Установить приложение» или «Добавить на главный экран».

## Подключение к серверу

В настройках клиента задаётся базовый URL сервера. Клиент ожидает:

- `GET /health` для проверки доступности, ответ JSON с полем `status: "ok"` или `status: "healthy"`.
- `POST /api/v1/chat` с JSON `{"message":"...","session_id":"...","client":"kii-mobile"}`.
- Успешный ответ JSON с текстовым полем `reply` (допустимы также `response` или `message`).

Серверный API реализован в `api/server.py`. Запусти его командой `py -m api.server` из корня репозитория. По умолчанию он доступен только на этом компьютере (`127.0.0.1:8000`). Для доступа с телефона по локальной сети настрой `KII_API_HOST`, `KII_API_TOKEN` и `KII_ALLOWED_ORIGINS` по инструкции в корневом README. В мобильных настройках укажи тот же API-ключ. Для внешнего доступа обязателен HTTPS; не открывай API в интернет без аутентификации и ограничений доступа.

## Локальные данные и ограничения

- Последние 100 сообщений сохраняются в localStorage текущего браузера.
- История пока не синхронизируется с компьютером.
- Кэшируется только статическая оболочка, не ответы API.
- Не вводи пароли, токены или секреты в сообщения. Аутентификация и безопасное хранение ключей будут отдельным этапом.
- Внешний шрифт Inter используется как улучшение оформления; без сети будет системный шрифт.

## Текущие ограничения и следующий этап

- API передаёт текст текущему ограниченному обработчику команд, а не полноценной языковой модели.
- История остаётся локальной для каждого браузера и пока не синхронизируется.
- Следующие этапы: единое хранилище истории, память KII и диалоговый движок.
