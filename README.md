# КИИ — Комплексный интеллектуальный интерфейс

Локальный прототип персонального ассистента. Сейчас развиваются безопасное ядро команд и серверный API для подключения клиента на телефоне. **Голосовой вывод временно выключен и будет подключён позже.**

## Текущие возможности

- Консольное ядро на Python.
- Ограниченный список безопасных команд Windows и открытие существующих файлов/папок.
- HTTP API для проверки связи и передачи текстовых команд.
- Мобильный PWA-клиент в папке `mobile/`.
- Голосовой модуль сохранён в проекте, но по умолчанию не запускается.

## Установка

Требуется Python 3.10 или новее. Из корня репозитория:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
py -m pip install -r requirements.txt
```

Запуск консольного ядра без голосового вывода:

```powershell
py main.py
```

## Серверный API

Запусти API на этом компьютере:

```powershell
py -m api.server
```

По умолчанию API слушает только `127.0.0.1:8000`.

- Проверка состояния: `GET http://127.0.0.1:8000/health`
- Команды: `POST http://127.0.0.1:8000/api/v1/chat`
- Документация API: `http://127.0.0.1:8000/docs`

Пример запроса:

```json
{
  "message": "помощь",
  "session_id": "local-test",
  "client": "kii-mobile"
}
```

Успешный ответ содержит поле `reply`. На этом этапе API передаёт сообщения текущему обработчику команд, а не большой языковой модели. Поэтому свободный диалог и долговременная память ещё не реализованы.

### Подключение телефона по локальной сети

Не открывай API наружу без ключа доступа. Для временного доступа в доверенной домашней сети открой PowerShell и задай переменные в том же окне:

```powershell
$env:KII_API_HOST = "0.0.0.0"
$env:KII_API_TOKEN = "замени-на-длинный-случайный-секрет"
$env:KII_ALLOWED_ORIGINS = "https://адрес-твоего-клиента"
py -m api.server
```

Если мобильный клиент размещён на другом адресе, укажи его точный origin в `KII_ALLOWED_ORIGINS`. Для локальной разработки по умолчанию разрешены `http://localhost:8080` и `http://127.0.0.1:8080`.

В настройках мобильного клиента укажи адрес сервера, например `http://192.168.1.20:8000`, и тот же API-ключ. Для реального внешнего доступа используй HTTPS, а не обычный HTTP. Не перенаправляй порт API напрямую из интернета.

### Переменные окружения

- `KII_API_HOST` — адрес привязки; по умолчанию `127.0.0.1`.
- `KII_API_PORT` — порт; по умолчанию `8000`.
- `KII_API_TOKEN` — ключ API. Обязателен при привязке к внешним интерфейсам.
- `KII_ALLOWED_ORIGINS` — список разрешённых origin через запятую.

## Голосовой модуль (отложен)

Голосовой код находится в `voice/tts.py`, но по умолчанию выключен. Голосовые зависимости вынесены в отдельный файл и не требуются для текущей разработки:

```powershell
py -m pip install -r requirements-voice.txt
```

Синтез голоса, распознавание речи и собственная модель голоса будут подключаться после реализации ядра, API и экранного присутствия KII.

## Безопасность

- KII не выполняет произвольные команды оболочки.
- API по умолчанию доступен только на самом компьютере.
- Для сетевого доступа требуется API-ключ.
- Не публикуй ключ в репозитории и не используй API без HTTPS за пределами доверенной сети.
